PCL2 下载不了 Minecraft 怎么办？2.99 版本下载修复指南

适用版本：PCL2 2.99.0.0 / 2.99.0.1 · 更新于 2026-10

如果你最近打开 Plain Craft Launcher 2（PCL2）的「下载」页，看到的是一行红字：

为遵守相关法律法规，PCL 暂时不再提供 MC 下载功能，非常抱歉 qwq……

这不是你的安装坏了，也不是网络问题。从 PCL2 2.99 开始，作者在代码里加了一个编译期开关 RestrictMcDownload，把原版游戏下载链路整体关掉了；到 2.99.0.1 更进一步，连「原版游戏」这个左侧入口和启动页的下载按钮也一起隐藏了。

先说结论：有三条路

  1. 降级到 2.14.x：还能用，但会失去 2.99 的新功能与修复；
  2. 手动改用其他启动器：HMCL、PCL-CE 等，但版本、整合包要重新整理；
  3. 给现有 PCL2 打补丁：保留最新版本，只把被关掉的下载能力还原回来 —— 也就是 pcl2-patch 做的事。

为什么会变成这样

PCL2 是开源项目，作者在源码里把相关代码保留成了两个分支：

  • 当 RestrictMcDownload = True 时，走「关闭下载」的提示分支；
  • 当它为 False 时，走正常的 DlClientListLoader 加载分支。

发布版把常量编成了 True，但正确的那条分支其实还在编译产物里。所以修复不需要重新实现功能，只需要把执行路径改回原本的那条分支 —— 这也是补丁体积小、风险低的原因。

用 pcl2-patch 修复（推荐）

工具是一个单文件 exe，图形界面，三步完成：

  1. 从 Releases 下载 pcl2-patch-gui.exe（约 335 KB）；
  2. 打开后把 Plain Craft Launcher 2.exe 拖进窗口，等检查项全绿；
  3. 点「打补丁」并确认。工具会自动备份成 .exe.bak，写入后回读自检。

打完重新启动 PCL2，「下载」页就会恢复成正常的版本列表。

常见疑问

会不会把启动器改坏？

工具在副本上操作，写入前后各探测一次，任何一步不通过都不会动原文件；并且会留下 .bak 备份，覆盖回去即可还原。

PCL2 更新后补丁会失效吗？

会。启动器更新会用官方文件覆盖，补丁随之消失。重新跑一次本工具即可。

为什么不用「破解版」？

网上流传的所谓破解版通常是整包替换，来源不可控、体积大、版本滞后，也可能被塞入额外程序。补丁只改被关闭的那几条执行路径，其余与官方版完全一致。

打完补丁还能正常更新吗？

能，但更新会覆盖补丁。建议在 PCL2 设置里关闭自动更新，需要升级时手动更新后再打一次。

补丁仅用于你自己拥有的启动器副本；本项目与 PCL 官方无关，使用前请自行评估风险。
