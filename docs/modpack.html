PCL2 整合包安装失败怎么办？

适用版本：PCL2 2.99.0.0 / 2.99.0.1

在 PCL2 的「下载 → 整合包」里点开一个整合包（比如 Modrinth 上的人气包），点击「安装」后没有反应，或者直接弹出：

为遵守相关法律法规，PCL 不再提供 MC 下载功能，非常抱歉 qwq……

这不是你的操作问题，也不是网络问题 —— 是 PCL2 2.99 把整合包安装链路一起关掉了。

为什么整合包也受影响

在 PCL2 的代码里，整合包安装方法开头有一道判断：

  • 当 RestrictMcDownload 为真时，直接抛出异常，安装流程终止；
  • 正常分支才会去找整合包对应的安装器（CurseForge / HMCL / MMC / MCBBS / Modrinth / 通用压缩包）。

因为发布版把常量编成了 True，所有从「下载页」发起的安装都会走到抛异常那条路上。对于还保留整合包页的版本，安装按钮本身也可能被隐藏。

怎么恢复

用 pcl2-patch 打一次补丁即可，它会把整合包安装的分派逻辑恢复成正常分支，并且按 PCL 版本自动选择对应的补丁项：

  1. 下载 pcl2-patch-gui.exe（约 335 KB，免安装）；
  2. 把 Plain Craft Launcher 2.exe 拖进窗口；
  3. 检查项全绿后点「打补丁」，完成后重启 PCL2。

之后从「下载 → 整合包」点安装就会正常进入下载与解压流程。

关于「本地导入整合包」

本工具不提供从本地压缩包导入整合包的能力，只恢复「从 PCL 内下载」的安装链路。原因很简单：下载来源的整合包来自 Modrinth、CurseForge 等有审核与哈希校验的源，可追溯；而本地导入会解压任意来源的压缩包，PCL 的安装流程还会扫描包内可执行文件并询问用户是否运行 —— 这是一条现成的诱导执行路径，不放出这个入口是有意为之。

其它排查方向

如果打完补丁仍然装不上，可以按这个顺序排查：

  • 网络：Modrinth / CurseForge 的 CDN 在部分地区不稳定，PCL 设置里可以换下载源；
  • 磁盘空间：整合包动辄几百 MB，解压还需要额外空间；
  • 路径含中文或特殊字符：个别整合包对路径敏感，建议放在纯英文目录；
  • Java 版本：安装完成后启动失败通常是 Java 不匹配，不是安装本身的问题。

补丁仅用于你自己拥有的启动器副本；本项目与 PCL 官方无关，使用前请自行评估风险。
